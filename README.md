# Emlak Yönetim Merkezi — GitHub Pages

## Yayınlama
1. GitHub üzerinde herkese açık yeni bir depo oluşturun (örn. emlak-yonetim).
2. Bu ZIP dosyasındaki **index.html**, **style.css**, **app.js** dosyalarını depo kök dizinine yükleyin. ZIP dosyasının kendisini yüklemeyin.
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Yayın adresiniz: https://KULLANICI_ADINIZ.github.io/emlak-yonetim/

## ÖNEMLİ: yalnızca tanıtım sürümü
Bu sürümde kullanıcı adı/şifre JavaScript dosyasında açıktır ve giriş alanları önceden dolduruludur. Gerçek yetkilendirme içermez.
İlan, müşteri, randevu ve satış kayıtları tarayıcının localStorage alanındadır: cihazlar ve ziyaretçiler arasında paylaşılmaz, merkezi veritabanı yoktur.
Gerçek müşteri bilgilerini, telefonları veya özel iş verilerini bu herkese açık sürüme girmeyin. GitHub Pages yalnızca statik site yayımlar; güvenli çok kullanıcılı sistem için sunucu ve veritabanı gerekir.
